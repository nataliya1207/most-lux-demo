# MOST LUX — дизайн-концепт WebNat

Неофициальный демонстрационный лендинг автосервиса MOST LUX в Самаре. Не является официальным сайтом компании и не подтверждает сотрудничество с ней.

## Запуск

Статический HTML/CSS/JavaScript, без сборки и внешних зависимостей. Откройте `index.html` или запустите любой локальный статический сервер из этой папки. Для GitHub Pages: ветка `main`, папка `/ (root)`.

## Возможности

- Адаптивная страница с мобильным меню и нижней панелью связи.
- Фильтрация услуг, интерактивное сравнение до/после с клавиатурным управлением.
- Галерея в нативном модальном диалоге, закрытие по Escape, возврат фокуса.
- Демо-форма с проверкой обязательных полей и телефона. Заявки не отправляются и не сохраняются. Обработчик и аналитика отсутствуют.
- Прямые ссылки на телефон, Telegram, Яндекс Карты и действующий сайт компании.
- Поддержка reduced motion, подписанные поля, видимый фокус, ссылка пропуска навигации.
