# MOST LUX — дизайн-концепт WebNat

Неофициальный демонстрационный лендинг автосервиса MOST LUX в Самаре. Статические HTML/CSS/JS, без сборки и библиотек; только Google Fonts: Onest и Unbounded.

Демо: https://nataliya1207.github.io/most-lux-demo/

## Запуск и публикация

Откройте index.html либо используйте любой статический сервер из этой папки. GitHub Pages: main / root. Метка noindex сохранена, аналитики и обработчика формы нет.

## Взаимодействия

9 направлений: 5 в фильтре «Обслуживание», 2 «Кузов», 2 «Уход и шины». Три независимых сравнения с pointer capture, клавиатурой, подсказкой и переключателями на экранах до 900 px. Галерея, мобильное меню и экран успешной демо-заявки с повторным заполнением. Форма не передаёт и не сохраняет данные; без JS отправка отключена. Анимации отключаются при prefers-reduced-motion: reduce.
